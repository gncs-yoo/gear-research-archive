# ⚙️ 기어·구동계 최신 연구 논문 아카이브 (Gear Research Archive)

**Powered by GNCS @ Hyundai Mobis**

## 🔗 라이브 웹사이트

**https://gncs-yoo.github.io/gear-research-archive/**

매일 아침 수집된 기어·구동계(드라이브트레인) 최신 연구 논문이 5단계 엔지니어링 분석 리포트와 함께 자동으로 게시됩니다.

## 📖 아카이브 소개

이 저장소는 기어·유성기어·감속기·전동계(drivetrain) 분야의 최신 학술 논문을 매일 선별·심층 분석하여 웹 아카이브로 제공합니다. 구동계 연구 실무자의 관점에서 각 논문을 5단계 프레임워크로 분석합니다.

## 🎯 수집 기준

- **분야**: 기어 설계·해석, 유성기어(플래너터리) 기어, 감속기/레듀서, 전동 효율, NVH, 치형 수정, 재료·열처리, 윤활, 변속기 구동계 전반
- **출처**: 학술 저널 및 학회 (Elsevier, Springer, MDPI, ASME, IEEE, SAE 등)
- **선별 기준**: 구동계 실무 설계·해석에 적용 가능한 정량 데이터 또는 신기법이 포함된 논문
- **주기**: 매일 07:30 KST 자동 수집

## 🧭 5단계 분석 프레임워크

각 논문 카드는 다음 5단계 심층 분석 리포트를 포함합니다.

1. **① 연구 배경 및 기술 한계점** — 기존 기술이 가진 한계와 연구 동기
2. **② 제안 메커니즘 및 해석·실험 방법론** — 제안 기법의 핵심 원리와 검증 방법
3. **③ 핵심 정량 데이터 및 실험 결과** — 효율·강성·소음 등 정량 비교 결과
4. **④ 모빌리티 구동계 실무 시사점 (Mobis Action Items)** — 현대모비스 구동계 개발 관점의 적용 가능성
5. **⑤ 핵심 요약 (Key Takeaway)** — 실무자가 바로 활용할 수 있는 한 줄 요약

## 🗂️ 저장소 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 웹 아카이브 페이지 (GitHub Pages 메인 페이지) |
| `gear-papers-archive.html` | 동일 아카이브의 원본 파일명 사본 |
| `papers.json` | 수집·분석된 논문 데이터 (구조화된 JSON) |

## 🔄 자동 업데이트

논문 데이터(`papers.json`)에 새 논문이 추가되면 렌더링 스크립트가 `index.html`을 재생성하고, 본 저장소에 자동 커밋·푸시합니다. GitHub Pages가 이를 즉시 반영하여 웹사이트가 항상 최신 상태로 유지됩니다.
